# BetterSoft Backend Task 1

This project implements **Backend APIs for managing comments** for a given task using Flask.

## Features
- Add, Edit, Delete, and Fetch Comments (CRUD operations)
- Each comment belongs to a task (task_id)
- Automated tests included for API endpoints

## Tech Stack
- Flask
- SQLite
- pytest (for testing)

## How to Run
1. Clone the repository
2. Install dependencies using `pip install -r requirements.txt`
3. Run the server using `python flask_backend.py`
4. Use Postman to test all CRUD operations
